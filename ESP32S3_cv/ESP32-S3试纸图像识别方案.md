# ESP32-S3 + USB相机水质试纸完整比色卡识别方案

版本：V2.0  
日期：2026-09-09  
方案状态：V1样机推荐方案

## 1. 最终方案

本项目只采用一条主路线：

> ESP32-S3  + MJPEG UVC USB相机 + 封闭恒定光源 + 固定试纸槽 + 右侧完整比色卡。

每一种试纸型号配置一块专用检测托盘。试纸放在托盘左侧固定槽中，右侧放置该型号所有检测项目、所有浓度档位的完整比色卡。顶部增加白、灰、黑基准块，用于判断照片是否偏色、过曝或欠曝。

ESP32-S3在同一张照片中读取湿试纸和完整比色卡，逐项目比较颜色，输出浓度档位和可信度。颜色无法可靠区分时返回范围或“需要复测”，不强行给出结果。

### 2.1 ESP32-S3负责

- 控制拍摄仓LED；
- 执行显色倒计时；
- 通过USB Host采集MJPEG照片；
- 从多张照片中选择清晰、曝光正常的一张；
- 检查白、灰、黑基准块；
- 读取固定ROI中的试纸色块和标准色块；
- 计算颜色差、浓度档位和可信度；
- 保存检测数据；
- 通过Wi-Fi或BLE发送结果

### 2.2 设计方案

- 试纸与比色卡必须出现在同一张照片中；
- 试纸色块和对应项目的标准颜色保持在同一水平线上；
- 比色卡放在试纸右侧，并尽量缩短试纸块与标准色块之间的距离；
- 试纸和比色卡处在同一平面，避免距离镜头不同造成曝光和清晰度差异；
- 一种试纸品牌和型号对应一块专用托盘；
- 托盘可重复使用，用户每次只更换试纸；
- 完整比色卡负责浓度判断；
- 白、灰、黑只负责曝光、偏色和光照均匀性检查；
- 四角定位块用于检测托盘方向和摄像头是否移位；
- 二维码保存托盘型号、比色卡批次和版本。

### 2.3 尺寸建议

首版托盘可以根据试纸长度和档位数量调整。

- 算法只读取每个色块中央约50%的区域，避开印刷边缘和污损。

尺寸最终以相机工作距离、视场和实拍像素数为准。

## 3. USB相机要求

不追求1080p和高帧率。试纸是静止物体，稳定颜色、近距离对焦和可控曝光比高分辨率更重要。

### 3.1 相机前检查

同时实拍托盘，检查:

- 所有色块是否清晰；
- 画面四角是否严重变暗；
- 颜色是否随着每一帧明显跳变；
- 试纸湿润后是否出现大面积高光；
- 摄像头在目标距离是否能够锁定焦点。

## 3.2. 相机使用流程

完整比色卡能够抵消一部分环境光偏差，但湿试纸和印刷油墨的反射特性不同，因此仍然需要稳定光源。

### 3.3 拍摄视角结构

- 摄像头固定在托盘正上方；
- 工作距离先在15至25 cm范围实测；
- 左右两侧使用相同LED灯分别照射，选择更佳的一端减小误差；
- LED照射试纸和比色卡；
- 左右照度尽量一致；
- 遮挡室内灯和太阳光；
- LED使用恒流驱动；
- 正式拍摄期间不使用低频PWM调光；
- LED与镜头错开角度，避免水滴产生直接反光；

### 3.4 拍摄流程

1. 在黑暗条件下测；
2. 打开LED；
3. 等待约1秒使灯光和摄像头状态稳定；
4. 丢弃最初若干自动调整帧；
5. 连续采集3至5张MJPEG；
6. 选择最清晰、反光最少的一张；
8. 开始本地图像处理。

## 4. ESP32-S3固件流程

```text
空闲
  -> 获取试纸型号和比色卡版本
  -> 用户浸泡试纸并按下开始
  -> 执行厂家规定的显色定时器
  -> 用户将试纸放入固定槽并关闭仓门
  -> 到达有效读取窗口
  -> 打开LED并采集3至5张MJPEG
  -> 图像质量检查
  -> JPEG解码为RGB888
  -> 读取白/灰/黑ROI
  -> 读取试纸ROI和完整比色卡ROI
  -> 逐项目计算色差
  -> 计算浓度档位和可信度
  -> 输出结果或要求复测
  -> 保存并同步App
```

## 5. 完整比色卡识别算法

### 5.1 固定ROI

每个试纸配置包含：

- 白、灰、黑基准块坐标；
- 四角定位块坐标；
- 每个试纸反应块坐标；
- 右侧每个标准浓度色块坐标；
- 每个项目的浓度标签；
- 显色时间和允许读取窗口；
- 风险分级规则。

坐标仅表示数据结构，实际数值通过样机标定生成。

### 5.2 图片质量门控

识别前检查：

- 定位块是否在允许范围；
- 白色是否过曝；
- 黑色是否过亮；
- 灰色是否明显偏黄、偏蓝或偏绿；
- 左右基准区亮度是否差异过大；
- 图像是否模糊；
- 试纸是否缺失或放反；
- ROI中是否存在大面积水滴高光；
- 拍摄时间是否处于允许读取窗口。

任一关键条件不满足时返回具体原因，例如：

```text
照片反光过强，请擦除托盘积水后复测
试纸未完全放入固定槽
比色卡可能受污染
已经超过有效读取时间
```
